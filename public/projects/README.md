# Imagens dos projetos

Coloque aqui os screenshots/previews dos projetos. Os nomes devem ser exatamente:

- `processmap.png` — preview do ProcessMap (proporção ~21:9, mín. 1600×686 recomendado)
- `catalogo.png` — preview do Catálogo de Produtos (proporção ~16:10, mín. 1280×800)
- `dra-carla.png` — preview da Landing Page Dra. Carla (proporção ~16:10, mín. 1280×800)

**Formatos aceitos:** `.png`, `.jpg`, `.webp` (se trocar a extensão, ajuste em [`components/Projetos.tsx`](../../components/Projetos.tsx) na propriedade `image` do projeto correspondente).

Enquanto a imagem não existir, o card mostra um gradiente brand com o ícone do projeto (fallback automático — não quebra o layout).

## Dica para tirar bons screenshots

1. Abra o projeto em modo escuro (combina com o tema do portfólio)
2. Use largura ~1440px no navegador
3. Capture a tela mais visualmente impactante (dashboard, fluxograma, etc.)
4. Compresse com [tinypng.com](https://tinypng.com) antes de subir
